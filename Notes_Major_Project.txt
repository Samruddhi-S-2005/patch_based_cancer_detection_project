Description of topic:
#Cancer Detection in Tissue Images:
-Doctors take a small tissue sample (biopsy) from a patient. That tissue is viewed under a microscope and converted into digital images. These images are called: Histopathology Images
-Doctors normally look at them manually to identify cancer cells.
But this process:
takes time
depends on doctor experience
sometimes errors happen
So researchers build AI models to help doctors detect cancer automatically.

#What is patch-based?:
-Tissue images are very large.ex-5000X5000 pixels, A neural network cannot process such a large image directly. So the image is divided into small pieces called: Patches
-Each patch may contain:
normal tissue
abnormal tissue (cancer)
The AI model studies each patch separately.

#What is Anomaly Detection?:
-Anomaly means: Something abnormal / unusual
Example: Normal tissue cells → regular pattern
Cancer tissue cells → irregular pattern
-So the AI model tries to detect:
normal pattern vs abnormal pattern
-If abnormal → possible cancer.

#What is Unimodal?:
-In AI research, modalities mean data types. Ex- image, text, audio.
-This project uses only images, hence called Unimodal(Single data type)

#What is Deep Learning Model?:
-Deep learning models are neural networks. The most common model used for images is: CNN – Convolutional Neural Network
-CNN learns patterns like:
shapes
textures
colors
cell structures

--a black box model is a system where for an input model gives output but we don't know how the model made the decision inside, hence the need of explainable ai.

#research gaps and their possible solutions:
Gap 1: Dependency on Fully Labeled Patch-Level Data(most models rely heavily on fully labeled patch-level data, requires manual annotation by medical experts and time-consuming and expensive)      --- solution:weakly supervised learning approach, labeling is done at wsi level,thereby reducing dependency on detailed annotations.
Gap 2: Lack of Anomaly Detection Approaches(existing methods focus on supervised classification techniques, limited in detecting unseen/rare cancer patters, require large labeled datasets.)       ---solution:anomaly detection techniques, model learns normal tissue patterns, identifies deviations as potential cancerous regions, reducing need for extensive labeled data
Gap 3: Loss of Global Context in Patch-Based Methods(patch-based models process small image regions, leading to loss of global contextual info, resulting in misclassification, especially in complex tissue structures)       ---solution:context-aware techniques such as overlapping patches, larger patch sizes, and aggregation of patch-level predictions to preserve spatial relationships and improve classification accuracy.
Gap 4: Poor Generalization Across Datasets(Models trained on a specific dataset often fail to generalize well to other datasets due to variations in staining, resolution, and imaging conditions.)      ---solution:data augmentation techniques such as rotation, flipping, brightness adjustment and normalization methods can be enabled.
Gap 5: Lack of Explainability in Deep Learning Models(models often acts as black boxes, pridictions without explaination, reduces trust and reliability in clinical applications.)     ---solution:Explainable AI techniques such as Grad-CAM, which generate heatmaps highlighting important regions in the image.

#problem statement:
Existing deep learning models for histopathology analysis depend on extensive labeled data, lack contextual understanding, generalize poorly across datasets, and do not provide explainable results. This creates a need for a robust and efficient system that reduces labeling dependency, improves contextual learning, enhances generalization, and provides interpretable outputs.

#Types of Abnormalities:
1. Nuclear Atypia
✔ Irregular nucleus shape
✔ Enlarged nuclei
✔ Dark staining (hyperchromasia)
2. Tumor Cell Density
✔ Dense clusters of abnormal cells
✔ Loss of normal spacing
3. Mitotic Activity
✔ Cells dividing rapidly
✔ Visible mitotic figures
4. Structural Distortion (Tissue Architecture)
✔ Irregular ducts
✔ Broken gland structures
5. Necrosis (OPTIONAL but GOOD)
✔ Dead tissue regions
✔ Pale / irregular areas


#Methodology:
1.Data Collection:(WSI)-gigapixels(cannot be directly used for training the modeel)
-we collect data from publicly available datasets such as TCGA(.SVS) and CAMELYON16(.tif).
-Using only one dataset can lead to overfitting, whereas multiple datasets improve robustness.
-tumor and normal samples
-abnormalities are not explicitly labeled. The model learns them implicitly through feature extraction.
2.Data Preprocessing:
-patch extraction:We divide each Whole Slide Image into smaller patches of size 224×224(standard input size for CNN models like imagenet, Large enough to capture: Cells, Tissue patterns.  Small enough to: Process efficiently)  using a sliding window approach. we need overlapping patch images, so patch size will be given 224x224, Stride(step size) <224 gives overlapping patches. overlapping patches captures boundary regions, improves detection accuracy, reduces missed features.
[sliding window working:Sliding window extracts fixed-size patches by moving across the image with a defined stride, ensuring full coverage of the WSI.]
-remove non informative patches:We remove empty or background patches using thresholding, so that the model focuses only on meaningful tissue regions. thresholding- steps- Convert patch to grayscale, Calculate average pixel intensity, Compare with threshold. condition-If > 80% pixels are white → remove patch , other methods-Otsu thresholding,  HSV color filtering, Morphological filtering
-noise reduction:We apply Gaussian blur to reduce noise while preserving important structures in the tissue. noise-Unwanted variations in image like scanner noise, staining variations, small pixel disturbances, ex:random dots, uneven color   , guassian blur-Smooths the image by averaging neighboring pixels, Each pixel = weighted average of neighbors, Nearby pixels → higher weight    , other methods-Median filter (can remove edges ❌), Bilateral filter (slow ❌)
-resizing and normalization:All patches are resized to a uniform size(224x224) and normalized to improve model performance. normalization-required for transfer learning. types:min-max scaling(converts to 0-1), mean-std normalization(formula:(pixel - mean) / std)), imagenet values-mean = [0.485, 0.456, 0.406] std  = [0.229, 0.224, 0.225]
-data augmentation:We apply augmentation techniques such as flipping, rotation, and zooming to increase dataset diversity, improve generalization and prevent overfitting.
3.Model Development:
-transfer learning:We use a pre-trained EfficientNet model trained on ImageNet and fine-tune it on our dataset. This reduces training time and improves performance.
-feature extraction:The model automatically extracts important features such as cell shape, texture, and structural patterns. This is done internally by convolutional layers. convolutional layers-A convolutional layer extracts features from an image by applying filters that scan across the image and generate feature maps representing important patterns such as edges, textures, and shapes.  EfficientNet uses MBConv blocks, which consist of expansion, depthwise convolution, squeeze-and-excitation, and projection layers. These blocks efficiently extract features while maintaining high accuracy with fewer parameters.
-classification:The model classifies each patch as either tumor or normal.
4.Anomaly And Risk Analysis:
-anomaly detection:The model identifies abnormalities such as nuclear atypia, increased cell density, mitotic activity, and tissue distortion.
-anomaly scoring:Each patch is assigned a probability score indicating how likely it is to be cancerous.Assigning a score to each patch
0 → Normal
1 → Tumor
Example:
0.2 → Low anomaly
0.8 → High anomaly
formula--Softmax / Sigmoid output
-risk prediction:Based on this probability, we categorize risk into three levels:
Low risk, Medium risk, High risk
5.Model Comparison:
-evaluation metrics:We evaluate the models using standard metrics including:
Accuracy-Correct predictions / total
Precision-Out of predicted tumors, how many are correct
Recall-Out of actual tumors, how many detected
F1-score-Balance of precision & recall . formula:F1 = 2 × (Precision × Recall) / (Precision + Recall)  F1 score is a measure that combines precision and recall into a single value.
-model selection:The best-performing model is selected based on these metrics.
6.Output:
-prediction:The model predicts whether the tissue is tumor or normal.
-risk level:It also provides risk classification such as low, medium, or high.
-heatmap visualization:We use Grad-CAM to generate heatmaps that highlight important regions in the image.(how grad cam works?- uses gradients from CNN and highlights influential areas
-deployment:The system can be deployed as a web application or API for real-world use.
